# NNNN. Short title that names the decision

- **Status:** Proposed | Accepted | Superseded by NNNN
- **Date:** YYYY-MM-DD
- **Applies to:** `path/to/file.ts`, `path/to/folder/`

## Context

What forced a choice. The constraint, the bug, the provider quirk, the number. Say what goes wrong if someone "fixes" the code back to the obvious version.

## Decision

What the code does and why. Short bullets are fine. Keep the numbers.

## Consequences

What this costs, what it rules out, and what to check when you change it.
